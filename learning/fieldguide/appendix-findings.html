APPENDIX G

Findings and errata

Things found while writing this book that look wrong, stale or risky in the builds and the learning system, each with its evidence and a suggested fix. None of them has been changed: the build repositories are yours and your build threads', so these are proposals for T1 to rule on.

G.1How to read this

Severity is a judgement about consequence, not effort. Medium: a control claim is weaker than it reads, or a misunderstanding is likely in front of a client. Low: a stale statement or a latent issue that would bite only if something else changes. Cosmetic: record-keeping. Every finding names the file and the date it was read; the build commits read were ARB adk-2.5.0 at 7e577e5 (mirrored on main at d4057c7) and pm-agent r1-build at 2d9dbb5.

# System Design Track — the agent is only as good as the system around it

**Updated:** 2026-10-14. **Why:** an agent that can't be served, secured, scaled, deployed and operated with ordinary system-design engineering has no production value. This track covers the end-to-end architecture around the agent, not only the agent.

**How it runs:** every SYS rep = learn one concept (≤ 25 min from a GROUND source) **+ apply it immediately** by writing or revising one section of `design/pm-agent-at-scale.md`, the production architecture for your own pm-agent. The design doc is the retention device: each concept lands on a system you know, and by the end you own a defensible end-to-end design you can present.
